# ¿Qué Onda?

Chilean news aggregator + live TV/radio streaming in a single-page, ad-free dashboard. Spanish UI, AGPL-3.0.

Sections (nav order): Emergencia · Noticias · TV · Radios · Ciberseguridad · Finanzas · YouTube · Spotify · Tendencias · Clima · Aire · Transporte · Deportes · Trabajos · Feriados · Fiestas Patrias.

## Stack

- Astro 7 (SSR) + React 19 + TypeScript + Tailwind CSS 4 + DaisyUI v5.
- Fonts: `Figtree` (body) + `Lora` (headings), loaded non-blocking via Google Fonts `<link>`.
- Icons: inline SVGs (no icon library). No animation library — CSS transitions + `active:scale` only.
- Sound: Web Audio API singleton (`src/lib/sound.ts`) — triangle wave + bandpass noise, lazy AudioContext.
- Maps: Leaflet (widget maps) + MapLibre GL via OpenFreeMap (lazy, shared basemap).
- Deploy: Cloudflare Pages Functions (SSR), `nodejs_compat`, `@astrojs/cloudflare` v14+ `mode: 'directory'` + `scripts/post-build-pages.mjs` post-build hook.
- Commands: `pnpm dev`, `pnpm build` (build + post-build restructure), `pnpm preview`. Regenerators: `pnpm run update-feeds` | `update-stops` | `update-holidays` | `sync-credits`.

## Architecture Notes

- Astro SSR serves only the shell — every widget fetches client-side via `fetch('/api/...')` or directly from CORS-enabled external APIs.
- **Two-tier server cache**: in-memory `Map` (L1) + Cloudflare Cache API `caches.default` (L2) + `dedupeFetch`; `edgeCacheHeaders(ttl)` for CDN caching, `noStoreHeaders()` for errors, `setLastGood`/`getStaleCached` for durable snapshots (power, cyber).
- **Pre-warm**: one inline `fetch()` batch inside a single `requestAnimationFrame` on load (emergency, power, news inventory, channels ×3, radios, youtube, trends, transport, air-quality, sports, futbol, jobs, spotify, cyber). No idle split.
- **Client IDB pattern** per widget: render from IndexedDB → background fetch → update IDB → server cache hit.
- Hydration tiers:
  - `client:load` (above fold): Header, SideIndex, BottomNav, EmergencyTicker, EmergencyWidget (mounts PowerOutageWidget), BackToTop.
  - `client:idle` (everything else): ClientNewsFeed, ClientTV, ClientRadios, CyberWidget, FinanceWidget, YouTubeTrends, SpotifyChart, GoogleTrendsWidget, WeatherWidget, AirQualityWidget, TransportWidget, FootballTable, JobList, HolidaysWidget, FiestasCountdown, Footer, SectionShareHandler.
- `clustering.ts` code-split via dynamic `import()` in ClientNewsFeed (shared with the article reader).
- `hls.js` dynamically imported only on user play for m3u8 streams (TV + radio); iframes for YT/Twitch channels.
- Cron: GitHub Action `*/30 * * * *` hits `/api/cron` with `Authorization: Bearer $CRON_SECRET` (sports, youtube, power, trends, cyber). Missing secret ⇒ 503.

## Theme System

- 35 DaisyUI v5 themes in `src/styles/global.css`. `data-theme` on `<html>` set by init script + `ThemeSwitcher`, persisted in `localStorage.theme`; fresh visitors start on `halloween` (CSS `--default` is `dark`).
- Semantic classes only: `bg-base-100..300`, `text-base-content[/70]`, `text-primary`, `bg-primary`, `text-primary-content`, `border-base-300`.
- `accent` is never used. Solid primary = `bg-primary text-primary-content`; translucent = `bg-primary/*` + `text-primary`. `.light-theme` class (not `@media color-scheme`) for light-theme CSS.

## Accessibility

Native elements first (`button`/`a`, never `div onClick`), visible `focus-visible` rings (`outline-2 outline-offset-2 outline-primary`), keyboard operable, skip link (`href="#main"`), `aria-live="polite"` for auto-updating emergency, `prefers-reduced-motion` respected on marquee/pulse/confetti. Overlays/modals: `role="dialog"` + `aria-modal` + focus trap + focus restore, `inert`/`aria-hidden` when visually hidden. No controls revealed only on hover.

## API Endpoints

All JSON, same-origin. TTLs are server cache values unless noted.

- `GET /api/news?mode=inventory` — OPML source list (~2400 feeds), 15 min.
- `POST /api/news/batch` — body `{ sources: string[] }` (max 40, canonicalized against inventory); per-source `rss:{url}` 15 min + batch cache; client IDB 10 min.
- `GET /api/channels?source=json-teles|iptv-org|mi-iptv&category=` — TV channels, 1 h (IDB 24 h). Used by ClientTV (CORS-free).
- `GET /api/finance` — UF/USD/EUR/IPC/UTM merge: mindicador → Boostr → findic → SII RSS → DolarAPI, 30 min. Fallback only; FinanceWidget fetches mindicador/dolarapi client-side first.
- `GET /api/youtube` — YouTube Chile trending via channel RSS, 60 min; `GET /api/youtube/source?channelId=&name=` retries one channel, 5 min.
- `GET /api/trends` — Google Trends Chile RSS, 30 min.
- `GET /api/weather?q=<ciudad>` or `?cities=a,b` (no params = default cities; `q`/`cities` mutually exclusive) — Open-Meteo → Gael Cloud → Boostr, 10 min; `{ weather: null }` with `no-store` when everything fails. WeatherWidget fetches Open-Meteo directly first; `/api/forecast` serves DMC 5-day forecast (1 h).
- `GET /api/transport?city=&stop=|route=|mode=route-names` — Metro.cl + Red.cl + DTPM GTFS stops (`stops-database.json`), 5 min (route-names 1 h).
- `GET /api/air-quality` — SINCA stations (PM2.5/PM10 + ICAP status) → Open-Meteo CAMS fallback, 30 min.
- `GET /api/sports` — sports RSS (OPML Deportes category + keyword-matched feeds), 30 min.
- `GET /api/futbol` — RSS articles only (`{ articles, sourceResults, totalSources, displayedSources }`), 10 min; FootballTable fetches ESPN standings/matches directly client-side.
- `GET /api/emergency` — `{ items, senapred }`; sismos: Gael Cloud → Boostr → USGS (mag ≥ 5.0), 5 min; `senapred` = SAE alerts scraped from the official Telegram channel.
- `GET /api/power` (+ `?fresh=1`, rate-limited 1 per 2 min per IP) — SEC clients without supply: totals, regions, comunas, hourly series. 15 min internal / 5 min edge. Single source, no fallback chain: on failure serves `power:lastgood` (6 h) with `stale: true`; if none, 502 `SEC no disponible` with `no-store`.
- `GET /api/cyber` — `{ alerts, kev, blocks, updatedAt }`; CSIRT Nacional alerts + CISA KEV (trimmed to 30/90 days, ransomware window 180 days), 15 min (3 min if a block failed); `cyber:lastgood` (6 h) with `stale: true` if both fail.
- `GET /api/holidays` — Boostr → Nager.Date → bundled `holidays.json`, 24 h. Fallback only; HolidaysWidget fetches nager.at directly.
- `GET /api/article?url=` — cheerio content proxy (redirect validation + `sanitizeArticleHtml`), 60 min per URL.
- `GET /api/radio-stations` — `{ stations, tags, states, stateCounts, total }`; radio-browser.info → json-teles → `FALLBACK_RADIOS`, 1 h (IDB 24 h).
- `GET /api/jobs?source=getonbrd|workanywhere|remotive` — `{ jobs, sources, sourcesMeta }` (no `source` = all in parallel), 1 h.
- `GET /api/spotify` — `{ title, thumbnailUrl }` oEmbed metadata for the "Top 50 Chile" card (chart is an iframe embed), 1 h.
- `GET /api/cron` — Bearer auth via `CRON_SECRET`; warms sports, youtube, power, trends, cyber.

### Data source fallback chains

Weather: Open-Meteo → Gael Cloud → Boostr (plus Open-Meteo Geocoding, DMC forecast, Windy radar).
Sismos: Gael Cloud → Boostr → USGS (≥ 5.0); SENAPRED SAE: official Telegram feed (separate block).
Finance: merge across mindicador → Boostr → findic → SII RSS → DolarAPI.
Air quality: SINCA (MMA) → Open-Meteo CAMS.
Radio: radio-browser.info → json-teles (Chilean music) → `FALLBACK_RADIOS`.
News feeds DB: `feeds-database.json` (bundled) → GitHub raw → jsDelivr.
TV: json-teles → iptv-org → mi-iptv (+ YouTube/Twitch live signals).
YouTube trending: json-teles → YouTube RSS. Holidays: Boostr → Nager.Date → bundled JSON.
Football: ESPN (client) → Sports RSS. Jobs: GetOnBrd → WorkAnywhere → Remotive.
Maps: OpenFreeMap → OpenMapTiles → OpenStreetMap.

## News System

- 6 slots, persisted to `localStorage['news-slots']` (sourceKeys). Pins in `localStorage['news-pins']` (`Record<number, { sourceKey, name, url }>`; a source can only be pinned to one slot and wins on reload).
- Default slots: Ciper Chile · Contrapoder Chile · ADN Radio · BioBioChile · La Tercera - Nacional · FastCheckCL.
- Source dropdown per slot (in-use sources disabled elsewhere), accent-insensitive search, A-Z/Z-A (`news-sort`), and "Solo principales por sitio" (`news-main-only`), both shared with `/todas-las-fuentes`. Dropdown groups all feeds of an outlet together, flagship feed first.
- No "Phase 3": clustering + trending computed client-side from the 6 active sources.
- `?tag=` URL param filters clusters + slots; "Limpiar" clears it.
- Clustering: keyword unigrams/bigrams/trigrams (stopwords removed) + Jaccard similarity (> 0.25 = same cluster), sorted by article count × source diversity.
- Caches: server per-source `rss:{url}` 15 min; client batch `news-batch:{keys}` (IDB 10 min); per-source `news-source:{key}` (IDB).

## TV & Radio Systems

TV: single `<video>` + one hls.js instance shared by inline and PiP; FLIP on mode switch; auto-PiP via IntersectionObserver; search, favorites, signal selector (HD/WEB/YT/Twitch); grid density 1–5 rows (`tv-grid-rows`), sort A-Z/Z-A (`tv-sort`), player placement `below|above|left|right` (`tv-player-placement`).
Multiview: 1–9 streams (`tv-view-mode`, `tv-multiview-layout` `1x1`…`3x3`, `tv-multiview-slots`), each cell with its own `<video>`/hls.js and signal selector.
Radio: boombox layout (player + list), hidden `<video>` + hls.js for HLS, `<audio>` for direct streams; ~500 stations rendered in batches of 40; sticky miniplayer; CD-disc visuals.
Both fetch channel/station lists via server endpoints (CORS-free) with IDB 24 h cache and hardcoded fallbacks.

## Widget Highlights

- **Emergency**: sismos + SENAPRED alerts + power outages; maps (sismos by magnitude, comunas), auto-refresh every 5 min + on tab focus, shared error box with auto-retry backoff (5/10/20/30/60 s).
- **Power**: SEC snapshot, region/comuna breakdown (collapsible, `power-breakdown`), % mode with zoom/real scale (`power-scale`), hourly evolution chart (24 h/48 h/72 h/7 d).
- **Cyber**: CSIRT alerts tab + CISA KEV tab, per-tab filters ("Solo críticas" / "Solo ransomware"), accent-insensitive search, batch rendering in a fixed-height window, `ArticleReader` for alerts.
- **Weather**: multi-city cards, opt-in geolocation, DMC 5-day forecast, Windy radar, IDB cache; chosen city in `weather-user-city`.
- **Air quality**: SINCA stations, ICAP band colors, region/comuna filters, Leaflet map.
- **Transport**: Metro lines/stations status + RED bus predictions, popular stops, route stops and route map.
- **Football**: ESPN standings + matches client-side, news tab with 25 RSS articles in a fixed-height window.
- **YouTube**: trending grid + channel feeds, batch rendering, in-page `VideoModal` player (modifier-click opens YouTube).
- **Fiestas Patrias**: countdown with seasonal messages and a daily card reveal (legendary card bursts confetti).

## Sound System

`src/lib/sound.ts` singleton: `play(role)`, `toggleMuted()`/`isMuted()`, `setVolume()`/`getConfig()`, `setMuted()`, `cleanup()`. 20 roles (`interaction.*`, `navigation.*`, `notification.*`, `overlay.*`, `media.*`, `hero.*`). Footer sound toggle persists via module state; mute preference in `localStorage`.

## Layout & Shared Components

- `Header` (fixed, hides on scroll down), `SideIndex` (right-side section index), `BottomNav` (mobile dock, auto-hides on scroll, "Más" sheet), `Footer` (photo credit + sound toggle + credits link), `Section` (letter-by-letter title + "Compartir sección" button), `SectionShareHandler` (one delegated island for all section shares), `BackToTop` (appears after 500 px, lifts above dock/sheet/player), `ShareButton` (native share on touch / clipboard on desktop).
- Section attribution: `SectionSources` reads `sections.<id>.sources` from `src/lib/data-sources.json` and renders right-aligned `Fuente:` / `Fuentes:` links (1 source ⇒ "Fuente"). Never hardcode attributions.
